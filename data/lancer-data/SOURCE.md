# Lancer game data

These JSON files are Massif Press's official LANCER data, unmodified, from
https://github.com/massif-press/lancer-data (npm `@massif/lancer-data` v4.0.12, "LANCER Core,
July 2020 Release").

LANCER is © Massif Press. This data is distributed under the GNU General Public License
v3.0 or later (GPL-3.0-or-later), as declared by its package. See
https://www.gnu.org/licenses/gpl-3.0.html.

Don't edit these files. Game-specific additions go in `data/game/`, never in here, so the
data can be updated by replacing this folder.
